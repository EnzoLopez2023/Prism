## Bounded source inventory

Behavior was read with `git show <commit>:<path>` from:

- `src/ChatApp.tsx` and `src/ChatAgent/PlexAgent/*`
- `src/AITest.tsx`, `src/AIImageTest.tsx`, `src/PromptLibrary.tsx`
- `src/ExcelToJsonConverter.tsx`
- `src/services/conversationService.ts`
- `src/utils/azureOpenAIClient.ts`
- `routes/ai.js`, `routes/conversations.js`, `routes/prompts.js`
- `lib/chatTools.js` only to enumerate and remove its direct cross-domain reads

The Hearth AppView shell and unrelated components, routes, providers, database
tables, theme, and deployment code were not copied.

## Data lineage

Legacy rows retain their source numeric ID in `legacy_source_id`. Conversation
and prompt rows also carry `source_lineage_json`, recording the source app,
commit, and database hash. Image bytes are written to content-addressed
filesystem objects; SQLite retains object key, SHA-256, MIME type, byte count,
message relationship, ordering, and legacy ID.

The four source-table canonical hashes are constants in
`lib/migration/prismLegacy.ts`. They were independently generated by the
coordinator's `hearth.sqlite-table-canonical.v1` oracle and are verified before
any target write.
